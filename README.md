# Ikarvo

Ikarvo is a Next.js 15 / React 19 app.

## Getting started

1. Install dependencies.

```bash
npm install
```

2. Copy `.env.example` to `.env.local` and fill in the values you need.

3. Start the dev server.

```bash
npm run dev
```

## Integrations

See `INTEGRATIONS-v11.md` for what each external integration needs.

## Quality gates

```bash
npm run typecheck
npm run lint
npm run test
npm run build
```

## What this repo is

This is the full source for the Ikarvo app, including API routes, components, lib, public assets, tests, scripts, and Supabase migrations.
